## Tener instalado NodeJS https://nodejs.org/en

## Crear un proyecto con Vite https://vite.dev/guide/
```bash <Terminal (cmd, powershell), cmd>
    npm create vite@latest
        y + enter
        nombre_proyecto + enter
        react + enter
        javascript + enter
```
## Instalacion de las dependecias y librerias
```bash <Terminal, cmd>
    cd nombre_proyecto
    npm install
    npm run dev
```
